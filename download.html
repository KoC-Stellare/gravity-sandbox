Download Gravity SandBox

Free for Windows and Linux. Your account, saved maps and friends are the same in the app and in the browser.

Windows

Windows 10 and 11, 64-bit

Download installer (.exe) Portable version (.zip)

The installer adds Start menu and desktop shortcuts. The portable version runs from any folder without installing.

Linux

64-bit, Ubuntu 22.04 or similar

Download AppImage

One file, nothing to install. Make it executable once (right-click → Properties → Allow executing file as program, or chmod +x GravitySandBox-Linux.AppImage), then double-click it.

On a Mac, or don’t want to install?

Play the same game in your browser, with nothing to install. Needs a desktop computer with keyboard and mouse, and a recent Chrome, Edge or Firefox.

Play in browser

Get playing on Windows in three steps

  1. DownloadClick “Download installer” above. The file is about 100 MB.
  2. InstallOpen the file. If Windows says “Windows protected your PC”, click More info and then Run anyway: the game is new and not code-signed yet.
  3. PlayStart the tutorial in The Lab, or jump straight into a map. Create a free account to save maps and play with friends.

Questions

Is it free?

Yes. There are no ads and nothing to buy.

Do I need an account?

No. Guests can play singleplayer. A free account lets you save your maps, add friends and host or join rooms.

Can app and browser players play together?

Yes. Rooms, invites and friends work across all versions.

How do I update?

Download the newest file from this page. On Windows run the installer again; on Linux replace the old AppImage. Your settings and account stay.

Something doesn’t work.

Tell us on GitHub and include your system and what happened.
